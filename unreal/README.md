# unreal/

El proyecto de Unreal Engine 5.8: **`unreal/IslaLaEncantada/IslaLaEncantada.uproject`** (creado el 25-oct-2026 con la plantilla First Person; movido aquí desde Documentos el 26-oct-2026 para sacarlo de iCloud).

- **Abrirlo:** doble clic en `IslaLaEncantada.uproject`, o en el Epic Games Launcher → Unreal Engine → Biblioteca → *Examinar* y elegir ese archivo.
- **Archivos pesados por Git LFS** (`.uasset`, `.umap`…); `Saved/`, `Intermediate/` y `DerivedDataCache/` no se suben (Unreal los regenera).
- **Claude controla el editor** por el plugin oficial *Unreal MCP*: al abrir el proyecto arranca un servidor en `http://localhost:8000/mcp` (ajuste en `Config/DefaultEditorPerProjectUserSettings.ini`). En Claude Code está registrado como `unreal`.
- Guía completa: [docs/04-unreal.md](../docs/04-unreal.md).
